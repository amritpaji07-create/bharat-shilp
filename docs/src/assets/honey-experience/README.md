# Honey Experience PNG Asset Pack

Contains 21 PNG assets: 7 category tiles, 7 jar images, and 7 product-card artworks.

## Folders
- `pick-a-honey/`: tall arched category tiles
- `honey-rail/jars/`: jar images for a horizontal rail
- `honey-cards/products/`: product-card artwork
- `previews/`: contact sheet preview

Use the PNGs as image assets in Angular. Keep product names, prices, ratings, wishlist controls, and add buttons as real HTML/Angular elements rather than relying on generated text embedded in images.
